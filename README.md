# Student Council Website

เว็บไซต์ตัวอย่างสำหรับสภานักเรียน ภาษาไทย โทนฟ้า ออกแบบเป็นหน้าเดียวและรองรับมือถือ

## วิธีเปิด

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งแพ็กเกจหรือ build โปรเจกต์

## ปรับเนื้อหาให้เป็นของโรงเรียน

- แก้ชื่อสภานักเรียน หัวข้อ โครงการ และตัวอย่างประกาศใน `index.html`
- ปรับสี ระยะ และรูปแบบใน `styles.css`
- เพิ่มการเชื่อมต่อระบบจริงใน `script.js` หากต้องการส่งแบบฟอร์มไปยังสภานักเรียน

การ์ดไอเดียและข่าวเป็นเนื้อหาตัวอย่าง แบบฟอร์มเก็บข้อความไว้ใน `localStorage` ของเบราว์เซอร์บนเครื่องนี้เท่านั้น และยังไม่ได้ส่งให้โรงเรียนหรือสภานักเรียน

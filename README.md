# Student Council Website

เว็บสภานักเรียนภาษาไทย โทนน้ำเงินเข้มและฟ้า สร้างเป็นหน้าเดียว รองรับมือถือ และไม่ต้องติดตั้งแพ็กเกจ

## วิธีเปิด

เปิด `index.html` ในเบราว์เซอร์ได้เลย

## ปรับเว็บ

- เปลี่ยนชื่อ คำอธิบาย โครงการ และข่าวตัวอย่างใน `index.html`
- ปรับสีและเลย์เอาต์ใน `styles.css`
- เพิ่มการเชื่อมระบบจริงใน `script.js` หากต้องการให้แบบฟอร์มส่งข้อมูลไปยังสภานักเรียน

แบบฟอร์มตัวอย่างไม่ขอชื่อหรือข้อมูลส่วนตัว และเก็บข้อความไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนี้เท่านั้น ยังไม่ได้ส่งไปที่ใด

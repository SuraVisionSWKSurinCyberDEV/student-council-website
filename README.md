# สภานักเรียนโรงเรียนสุรวิทยาคาร

เว็บไซต์ภาษาไทย/อังกฤษสำหรับสภานักเรียนโรงเรียนสุรวิทยาคาร จังหวัดสุรินทร์ ใช้โทนฟ้าเป็นหลักและเสริมสีเขียว–เหลืองของโรงเรียน ออกแบบให้รองรับมือถือและคอมพิวเตอร์ โดยไม่ต้องติดตั้งแพ็กเกจ

## ส่วนต่าง ๆ ของเว็บไซต์

- แนะนำสภานักเรียนและหลักการทำงาน
- อัตลักษณ์โรงเรียน: คติพจน์ ปรัชญาการศึกษา สีประจำโรงเรียน และความหมายของวงแหวนสามวง
- ทีมงาน โครงการ ข่าวสาร และแกลเลอรี
- สลับภาษาไทย/อังกฤษ
- เคลื่อนไหวเบา ๆ พร้อมรองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์

ข้อมูลทีม โครงการ ข่าว และภาพกิจกรรมยังเป็นส่วนตัวอย่างหรือพื้นที่รอข้อมูลจริง ไม่ได้อ้างว่าเป็นประกาศหรือผลงานอย่างเป็นทางการ และเว็บไซต์ยังไม่มีระบบหลังบ้าน แบบฟอร์มติดต่อ หรือบัญชีผู้ดูแล

## เปิดและแก้ไขเว็บไซต์

เปิด `index.html` ในเบราว์เซอร์ได้เลย เนื้อหาสองภาษาและข้อมูลตัวอย่างอยู่ใน `app.js`; สีและการจัดหน้าอยู่ใน `styles.css` ส่วน `favicon.svg` เป็นสัญลักษณ์วงแหวนแบบวาดใหม่เพื่อสื่อความหมาย ไม่ใช่ตราโรงเรียนฉบับทางการ

## เผยแพร่ด้วย GitHub Pages

ใน repository เปิด Settings → Pages เลือก Deploy from a branch, เลือก branch ที่ต้องการเผยแพร่ และโฟลเดอร์ `/(root)` แล้วบันทึก
